# Web3 钱包岗位学习计划

这个仓库用于系统化准备 **交易所 / 托管钱包开发岗位**，重点覆盖：

- 主流链集成与链适配
- 钱包与后台系统接口开发
- 链上业务与智能合约基础
- 合规钱包支持
- 钱包安全策略与安全架构升级
- Java 分布式工程能力

## 仓库结构

- `docs/4-week-plan.md`：4 周完整复习计划
- `docs/2-week-sprint.md`：2 周冲刺版计划
- `docs/interview-checklist.md`：面试准备清单
- `progress.md`：每日打卡模板

## 建议使用方式

### 1. 先过一遍 4 周主计划
适合：
- 有 Java 后端基础，但缺少交易所钱包经验
- 想系统补齐链、钱包、安全、工程知识

### 2. 时间紧就走 2 周冲刺版
适合：
- 面试时间很近
- 已经具备一定区块链或后端基础

### 3. 每天执行 3 个动作
- 输入：学习 2~3 小时
- 输出：写 30~60 分钟笔记 / 图 / 总结
- 表达：口头回答 20~30 分钟

### 4. 每周做一次复盘
建议重点检查是否已经能清楚讲出：
- BTC / ETH / SOL / TON 的差异
- 充值、提币、归集、冷热钱包流程
- 私钥管理与签名服务隔离
- Java + MySQL + Redis + MQ 在钱包系统中的落地方式

## 核心准备目标

准备完成后，至少要能独立讲清以下 6 个主题：

1. BTC / ETH / SOL / TON 的链模型和交易差异
2. 交易所钱包整体架构
3. 充值流程与确认策略
4. 提币流程、状态机与风控
5. 归集、热转冷与资金调度
6. 私钥管理与安全体系

## 推荐复习顺序

1. 区块链基础
2. 主流链交易解析与签名
3. 钱包系统设计
4. 安全与合规
5. Java 分布式工程能力
6. 高频面试题与项目表达

## 面试表达建议

如果你没有完整交易所钱包经验，建议突出：

- 自己的 Java / 分布式后端能力
- 对 BTC / ETH / SOL / TON 的系统理解
- 对高一致性、高安全系统的工程经验
- 对支付、清结算、账户、风控能力向钱包岗位的迁移

## 下一步

建议按以下顺序推进：

- 先看 `docs/4-week-plan.md`
- 再建立自己的每日打卡记录到 `progress.md`
- 每周结合 `docs/interview-checklist.md` 做一次模拟面试
