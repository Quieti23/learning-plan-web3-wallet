# 交易所 / 托管钱包岗位四周学习计划

> 目标岗位：区块链钱包高级开发 / 架构师（Java，BTC / ETH / SOL / TON，MySQL / Redis / MQ）  
> 建议投入：每天 3～4 小时，连续 28 天  
> 每日节奏：学习 90 分钟 + 实践 60～90 分钟 + 输出 30 分钟 + 口述 30 分钟

## 执行规则

每天必须完成三类动作：

1. **输入**：理解当天知识，不以“看完资料”为完成标准。
2. **输出**：形成可检查的笔记、代码、图或表格，并保存到仓库。
3. **表达**：不看资料口头回答当天问题，每题控制在 2～5 分钟。

口头回答统一使用以下结构：

> 结论 → 原理 → 生产实现 → 异常与风险 → 监控和恢复

完成标准：

- [ ] 当日任务全部完成
- [ ] 能不看资料回答至少 80% 的问题
- [ ] 回答中至少包含一个生产异常场景
- [ ] 将薄弱点记录到 `progress.md`

> 安全说明：所有链上实践仅使用测试网和无价值测试密钥；不要把助记词、私钥或 API Key 提交到仓库。

## 建议评分方法

每天对口述回答自评 1～5 分：

- **1 分**：只能说出名词。
- **2 分**：能解释基本原理。
- **3 分**：能给出正常生产流程。
- **4 分**：能覆盖异常、安全、监控和恢复。
- **5 分**：能比较方案、说明取舍，并接受连续追问。

面试前，核心问题应达到 4 分以上；没有达到时，优先补流程和异常处理，不要继续堆砌术语。
