# 4 周复习计划

适合对象：
- 有 Java 后端基础，但没有完整交易所钱包经验
- 想系统准备 Web3 钱包 / 交易所钱包 / 托管钱包岗位

目标：
- 能讲清主流链差异
- 能设计钱包核心流程
- 能解释安全与私钥管理
- 能把 Java 工程能力落到钱包场景

---

## 使用说明
- 每天学习建议投入 2 ~ 3 小时
- 学习顺序建议：先理解概念，再看资料，再做输出
- 每天至少完成一个“输出”，避免只看不练
- 若时间紧张，可优先完成“核心必学”和“当日输出”

## 第 1 周：区块链基础 + 主流链差异

### 目标
- 搞懂 BTC / ETH / SOL / TON 的基本交易模型
- 理解确认数、重组、手续费、签名、充值解析

### Day 1：区块链基础总览
**学习内容**
- 区块、交易、状态、共识
- mempool、确认数、finality
- 分叉、链重组、回滚
- 主网 / 测试网 / RPC

**推荐资料**
- Bitcoin Whitepaper：先看电子现金系统、区块与 PoW 核心思想
- Ethereum Docs：Introduction / Transactions / Blocks
- Solana Docs：Introduction to Solana
- TON Docs：基础概念、账户与消息模型概览

**核心必学**
- 一笔交易从“发起 → 进入网络 → 打包 → 确认 → 最终确认”的完整过程
- 什么是确认数，为什么确认数不是绝对 finality
- 为什么会发生分叉与链重组

**输出**
- 写 1 页《交易生命周期》笔记
- 口头讲一遍“一笔交易从发起到确认”

### Day 2：UTXO vs Account

- ETH 的 Account 模型

输出：
- 对比表：UTXO vs Account

### Day 4：ETH / EVM
